MaKo EDIFACT Sanitizer

EDIFACT-Nachricht einfügen, lokal im Browser pseudonymisieren und anschließend die bereinigte EDIFACT-Datei sowie einen JSON-Report kopieren oder herunterladen.

Keine Übertragung: Diese statische Beispielseite verarbeitet die Eingabe lokal im Browser. Für EDIFACT-Inhalte gibt es keine Telemetrie, keine externe API und keine Netzwerkanfrage. Die Browser-Logik wird aus der npm-/Library-Implementierung src/index.js gebaut. Das ist ein Pseudonymisierungs-Hilfsmittel, keine garantierte DSGVO-Anonymisierung und keine Rechtsberatung. Ergebnis vor Weitergabe immer fachlich prüfen.

Bitte nur synthetische, anonymisierte oder ausdrücklich freigegebene Daten verwenden. Das mitgelieferte Beispiel ist synthetisch.
